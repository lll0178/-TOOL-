  AI C++ Fixer 1.0.1  ·  C/C++ AI 错误修复插件
════════════════════════════════════════════

【这是什么】
VS2022/VS2026 插件：读取 MSVC 编译错误，调用大模型（默认 DeepSeek，
可换任意 OpenAI 兼容接口）给出多种修复做法，灯泡/右键一键预览并应用。

【接收方要求】
1. Windows 系统，已安装 Visual Studio 2022（17.x）或 VS2026（18.x），
   且包含“Visual Studio 核心编辑器”组件（正常安装都带）
2. 安装时具备管理员权限（点一次 UAC 确认）
3. 自己准备一个大模型 API Key（DeepSeek 等），插件不内置任何密钥

【安装步骤】
方式一（推荐）：双击本文件夹里的 “安装插件.cmd”
    → UAC 弹窗点“是” → 等它提示完成 → 关闭所有 VS 窗口后重开 VS
方式二：直接双击 CppAiFixer.vsix
    → 在向导里勾选你的 Visual Studio 版本 → 安装

【首次配置（必做）】
打开 VS → 工具 → 选项 → AI C++ Fixer：
  API 地址：默认 https://api.deepseek.com （可换成其他 OpenAI 兼容地址）
  API Key ：填自己的密钥（也可设环境变量 DEEPSEEK_API_KEY 后留空）
  模型    ：默认 deepseek-chat
切换其他 API 的完整说明见《API配置指南.md》（如不需要可忽略）。

【使用方法】
1. 在 C/C++ 文件里写代码，按 Ctrl+F7 编译当前文件
2. 光标放到报错行：点灯泡“AI 修复 …”，或右键“AI 修复光标处错误”
3. 弹窗列出 AI 提出的多种做法 → 选择 → 预览差异 → 应用（可 Ctrl+Z 撤销）
4. 想批量修复：右键“AI 修复当前文件错误”，逐条确认/跳过

【卸载】
VS 菜单 扩展 → 管理扩展 → 已安装 → AI C++ Fixer → 卸载；
或管理员终端执行：
  VSIXInstaller.exe /quiet /u:CppAiFixer.9e6f5a2d-4b7c-4d3e-8a1f-2c5b9e7d4a31

【安全说明】
本插件未做数字签名，安装时 Windows SmartScreen / VS 可能提示“未知发布者”，
属正常现象；如果你从可信任的渠道拿到本包，点击“仍要安装”即可。
