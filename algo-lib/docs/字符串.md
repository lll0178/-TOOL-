# 字符串（String）

本分类收录字符串相关的算法与数据结构模板。所有接口位于 `namespace algo` 内，
头文件位于 `include/string/`，库内依赖统一使用 `#include "algo/xxx.hpp"` 风格。

字符串下标一律 **0-based**。除特别说明外，模式匹配相关接口均允许重叠匹配。

---

## 1. KMP —— `include/string/kmp.hpp`

**功能**：KMP 字符串匹配、前缀函数（next 数组）与最小循环节。

**主要接口**：

```cpp
std::vector<int> kmp_build_next(const std::string& s);
std::vector<int> kmp_match(const std::string& text, const std::string& pat);
int min_cycle(const std::string& s);
```

- `kmp_build_next(s)`：返回 `next` 数组，`next[i]` = 前缀 `s[0..i]` 的最长真公共前后缀长度，`next[0] = 0`。
- `kmp_match(text, pat)`：返回 `pat` 在 `text` 中所有出现位置的起始下标（可重叠）。
- `min_cycle(s)`：返回最小循环节长度。`len = n - next[n-1]`，若 `n % len == 0` 返回 `len`，否则返回 `n`。

**用法示例**：

```cpp
#include "string/kmp.hpp"
using namespace algo;

std::vector<int> pos = kmp_match("abababa", "aba"); // {0, 2, 4}
std::vector<int> nxt = kmp_build_next("aabaaab");   // {0,1,0,1,2,2,3}
int cyc = min_cycle("abcabc");                      // 3
```

**复杂度**：`kmp_build_next` / `min_cycle` O(n)；`kmp_match` O(|text| + |pat|)；空间 O(n)。

**注意事项**：`next[i]` 是“真”前后缀长度（不含自身）。空模式串约定返回空结果；
`min_cycle` 对空串返回 0。

## 2. Z 函数（扩展 KMP）—— `include/string/z_algorithm.hpp`

**功能**：Z 函数与基于 Z 函数的模式匹配。

**主要接口**：

```cpp
std::vector<int> z_function(const std::string& s);
std::vector<int> z_match(const std::string& text, const std::string& pat);
```

- `z_function(s)`：`z[i] = LCP(s, s[i..])`，约定 `z[0] = 0`。线性实现，维护最右匹配区间 `[l, r]`。
- `z_match(text, pat)`：构造 `pat + '#' + text` 的 Z 数组，返回 `pat` 在 `text` 中所有出现位置的起始下标。

**用法示例**：

```cpp
#include "string/z_algorithm.hpp"
using namespace algo;

std::vector<int> z = z_function("aabxaabx"); // {0,1,0,0,4,1,0,0}
std::vector<int> pos = z_match("ababa", "aba"); // {0, 2}
```

**复杂度**：O(n)（`z_match` 为 O(|text| + |pat|)）；空间 O(n)。

**注意事项**：`z[0]` 恒为 0。`z_match` 用 `'#'` 作分隔符；由于判断只看 `z[i] >= |pat|`，
即使 `text` 中出现 `'#'` 也不影响正确性。空模式串约定返回空结果。

## 3. Manacher 最长回文 —— `include/string/manacher.hpp`

**功能**：线性求最长回文子串（统一奇偶处理）。

**主要接口**：

```cpp
std::vector<int> manacher(const std::string& s);
std::string longest_palindrome(const std::string& s);
```

- `manacher(s)`：插入 `'#'` 分隔符得到处理串（长度 `2n+1`），返回半径数组 `d`（`d[i]` 含中心）。
  原串最长回文长度 = `max(d) - 1`。
- `longest_palindrome(s)`：利用 `d` 还原出最长回文子串（自动处理奇偶）。

**用法示例**：

```cpp
#include "string/manacher.hpp"
using namespace algo;

std::vector<int> d = manacher("abba");          // 处理串 "#a#b#b#a#"，max(d)=5
std::string p = longest_palindrome("babad");    // "bab"（或 "aba"）
```

**复杂度**：O(n)；空间 O(n)。

**注意事项**：`d[i]` 含中心，处理串中回文长度为 `2*d[i]-1`，原串中为 `d[i]-1`。
原串起点 = `(i - d[i] + 1) / 2`。空串返回空串，单字符返回该字符。

## 4. 字典树 / 01 字典树 —— `include/string/trie.hpp`

**功能**：小写字母字典树与 01 字典树。

**主要接口**：

```cpp
class Trie {
    Trie();
    void insert(const std::string& s);
    bool find(const std::string& s) const;
    int count_prefix(const std::string& s) const;
    int count_exact(const std::string& s) const;
};

class BinaryTrie {
    BinaryTrie();
    void insert(long long x);
    void erase(long long x);
    long long max_xor(long long x) const;
};
```

- `Trie`：节点池 `vector<array<int,26>>` 动态开点，根为 0；节点记录 `cnt`（前缀计数）
  与 `end_cnt`（结尾计数）。`count_prefix` 返回以 `s` 为前缀的字符串数，
  `count_exact` 返回与 `s` 完全相等的字符串数。
- `BinaryTrie`：01 字典树，固定 31 位（可改为 63），支持插入、删除、查询与 `x`
  异或的最大值。

**用法示例**：

```cpp
#include "string/trie.hpp"
using namespace algo;

Trie t;
t.insert("abc"); t.insert("abd");
t.find("abc");        // true
t.count_prefix("ab"); // 2
t.count_exact("abc"); // 1

BinaryTrie bt;
bt.insert(3); bt.insert(5);
bt.max_xor(6);        // 5（6^3 = 5, 6^5 = 3，取最大）
```

**复杂度**：`Trie` 各操作 O(|s|)；`BinaryTrie` 各操作 O(BITS)。

**注意事项**：`Trie` 仅支持小写字母。`BinaryTrie` 假定 `x` 非负，`erase` 前须保证已插入。

## 5. AC 自动机 —— `include/string/ac_automaton.hpp`

**功能**：多模式匹配（同时匹配多个模式串，支持互为前缀的计数）。

**主要接口**：

```cpp
class ACAutomaton {
    ACAutomaton();
    void insert(const std::string& s);
    void build();
    std::vector<int> query(const std::string& text) const;
};
```

- `insert(s)`：插入模式串，按插入顺序编号 `0..m-1`。
- `build()`：BFS 建 fail 指针并补全缺失转移（查询 O(1)）。
- `query(text)`：返回长度 m 的 `vector<int>`，第 i 项为模式串 i 的出现次数
  （含互为前缀：走 fail 链，用拓扑序一次性累加）。

**用法示例**：

```cpp
#include "string/ac_automaton.hpp"
using namespace algo;

ACAutomaton ac;
ac.insert("he"); ac.insert("she"); ac.insert("her");
ac.build();
std::vector<int> ans = ac.query("ushers"); // he:1, she:1, her:1
```

**复杂度**：`insert` O(|s|)；`build` O(节点数 × 26)；`query` O(|text| + 节点数)。

**注意事项**：仅支持小写字母（`query` 忽略非小写字符）；必须先 `build()` 再 `query()`。

## 6. 后缀数组 —— `include/string/suffix_array.hpp`

**功能**：后缀数组（倍增 + 计数排序）、height 数组、O(1) LCP 与本质不同子串计数。

**主要接口**：

```cpp
class SuffixArray {
    SuffixArray(const std::string& s);
    const std::vector<int>& sa() const;
    const std::vector<int>& rk() const;
    const std::vector<int>& height() const;
    int lcp(int i, int j) const;
    long long distinct_substrings() const;
};
```

- `sa()`：`sa[i]` = 字典序第 i 小的后缀起始下标。
- `rk()`：`rk[i]` = 后缀 i 的名次。
- `height()`：`height[i] = LCP(sa[i], sa[i-1])`（i ≥ 1），`height[0] = 0`。
- `lcp(i, j)`：后缀 i 与 j 的 LCP，O(1)（内部倍增稀疏表 RMQ）。
- `distinct_substrings()`：`n(n+1)/2 - Σ height[i]`。

**用法示例**：

```cpp
#include "string/suffix_array.hpp"
using namespace algo;

SuffixArray sa("banana");
sa.lcp(1, 3);             // 3（LCP("anana","ana")）
sa.distinct_substrings(); // 本质不同子串个数
```

**复杂度**：构建 O(n log n)；`lcp` O(1)；`distinct_substrings` O(n)；空间 O(n log n)。

**注意事项**：字符按 `unsigned char`（0..255）计数排序，支持任意单字节字符。
空串时各数组为空，`distinct_substrings()` 返回 0，请勿对空串调用 `lcp`。

## 7. 后缀自动机 —— `include/string/suffix_automaton.hpp`

**功能**：后缀自动机（SAM），支持本质不同子串计数与 endpos 大小计算。

**主要接口**：

```cpp
class SAM {
    SAM();
    void build(const std::string& s);
    void extend(int c);
    long long distinct_substrings() const;
    const std::vector<int>& endpos_size() const;
};
```

- `build(s)` / `extend(c)`：逐字符在线建机（小写字母，标准实现含 clone）。
- `distinct_substrings()`：`Σ(len[v] - len[link[v]])`。
- `endpos_size()`：返回每个状态的 endpos 集合大小（按 len 计数排序，从大到小累加到 link）。

**用法示例**：

```cpp
#include "string/suffix_automaton.hpp"
using namespace algo;

SAM sam;
sam.build("ababa");
sam.distinct_substrings();        // 9
const std::vector<int>& sz = sam.endpos_size();
```

**复杂度**：`build`/`extend` 均摊 O(1)（总 O(n)）；`distinct_substrings` O(状态数)；
`endpos_size` 首次 O(状态数 + max len)，之后缓存。空间 O(状态数 × 26)，状态数 ≤ 2n。

**注意事项**：`next` 用 `array<int,26>`，仅支持小写字母；`distinct_substrings` 返回
`long long` 避免溢出；`endpos_size()` 下标为状态编号（0 为初始状态）。

## 8. 字符串哈希 —— `include/string/rolling_hash.hpp`

**功能**：自然溢出单哈希与双哈希，O(1) 求任意子串哈希。

**主要接口**：

```cpp
class StringHash {
    StringHash(const std::string& s);
    unsigned long long get(int l, int r) const;
};

class StringHashDouble {
    StringHashDouble(const std::string& s);
    std::pair<unsigned long long, unsigned long long> get2(int l, int r) const;
};
```

- `StringHash`：自然溢出单哈希（`ull` 自动 mod 2^64），固定 base = 131；
  `get(l, r)` 返回闭区间 `[l, r]` 的哈希。
- `StringHashDouble`：双哈希（第一维自然溢出 base 131，第二维模 1e9+7 base 13331）；
  `get2(l, r)` 返回 `pair<ull, ull>`。

**用法示例**：

```cpp
#include "string/rolling_hash.hpp"
using namespace algo;

StringHash h("ababa");
unsigned long long x = h.get(0, 2);  // "aba"

StringHashDouble hd("ababa");
auto y = hd.get2(1, 3);              // "bab" 的双哈希
```

**复杂度**：预处理 O(n)；单次查询 O(1)；空间 O(n)。

**注意事项**：乘法 `a * b` 在 `unsigned long long` 下自然溢出（等价 mod 2^64），
无需 `__int128`。单哈希存在碰撞风险，竞赛中建议双哈希；`get`/`get2` 要求
`0 <= l <= r < n`。
