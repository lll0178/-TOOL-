# 图论（Graph）

本目录收录图论相关板子。除特别说明外：

- 顶点编号一律 **1..n**（`n` 为顶点数）。
- 带权图用 `const vector<vector<Edge>>& g`（`Edge` 见 `algo/common.hpp`，含 `int to; ll w;`）。
- 无权图用 `const vector<vector<int>>& g`。
- 不可达距离用 `algo::INF` 表示；判断不可达用 `== INF`，**不要对 INF 做加法**。
- 头文件位于 `include/graph/`，使用时基于 `-I include` 以 `#include "graph/xxx.hpp"` 引入。

## dijkstra.hpp —— 堆优化 Dijkstra

**功能**：求带非负边权图（有向或无向）从源点 `s` 到其余各点的最短距离，可记录前驱还原路径。

**主要接口**：

```cpp
std::vector<ll> dijkstra(int n, const std::vector<std::vector<Edge>>& g,
                         int s, std::vector<int>* pre = nullptr);
```

- 返回 `dist[1..n]`，`dist[s] = 0`，不可达为 `INF`。
- `pre` 非空时记录前驱：`(*pre)[v] = 到达 v 的前驱点`，源点前驱为 `-1`。

**用法示例**：

```cpp
vector<int> pre;
vector<ll> d = dijkstra(n, g, 1, &pre);
// 还原 1 -> t 的路径：
vector<int> path;
for (int v = t; v != -1; v = pre[v]) path.push_back(v);
reverse(path.begin(), path.end());
```

**复杂度**：时间 `O((n + m) log n)`，空间 `O(n + m)`。

**注意事项**：边权必须非负；重边、自环均正确处理；不可达判断用 `d[v] == INF`。

## spfa.hpp —— SPFA 与 Bellman-Ford

**功能**：求可含负权边的单源最短路，并检测负环。

**主要接口**：

```cpp
bool spfa(int n, const std::vector<std::vector<Edge>>& g, int s, std::vector<ll>& dist);

struct BFEdge { int u, v; ll w; };   // 边表版用的边（命名唯一）
std::vector<ll> bellman_ford(int n, const std::vector<BFEdge>& edges,
                             int s, bool& has_neg_cycle);
```

- `spfa`：`dist` 需预先初始化为 `INF`（函数内把 `dist[s]` 置 0）；返回 `true` 表示检测到**从 s 可达**的负环（此时 `dist` 无意义）。用入队次数 `cnt[v] >= n` 判负环。
- `bellman_ford`：边表版（`BFEdge` 含 `u/v/w`），返回 `dist[1..n]`，`has_neg_cycle` 输出是否存在从 s 可达的负环。

**用法示例**：

```cpp
vector<ll> dist(n + 1, INF);
bool neg = spfa(n, g, 1, dist);

vector<BFEdge> edges;
bool has_neg = false;
vector<ll> d2 = bellman_ford(n, edges, 1, has_neg);
```

**复杂度**：SPFA 最坏 `O(nm)`（平均 `O(km)`）；Bellman-Ford `O(nm)`。

**注意事项**：两者都只能检测从源点可达的负环；SPFA 在构造数据上可能退化，非负权请用 Dijkstra。

## floyd.hpp —— Floyd-Warshall 与传递闭包

**功能**：求全源最短路（支持负权，不允许负环）；求传递闭包。

**主要接口**：

```cpp
void floyd(std::vector<std::vector<ll>>& d);

std::vector<std::vector<bool>> transitive_closure(int n,
    const std::vector<std::pair<int,int>>& edges);
```

- `floyd`：原地更新 `d`（下标 `1..n`）。调用前需初始化：`d[i][i] = 0`、无边处 `INF`、边权填入。
- `transitive_closure`：返回 `(n+1)x(n+1)` 的 bool 矩阵，`reach[i][j]` 表示 `i` 能否到达 `j`。

**用法示例**：

```cpp
vector<vector<ll>> d(n + 1, vector<ll>(n + 1, INF));
for (int i = 1; i <= n; ++i) d[i][i] = 0;
d[1][2] = 5; d[2][3] = 2;
floyd(d);
```

**复杂度**：时间 `O(n^3)`，空间 `O(n^2)`。

**注意事项**：负环会导致 `d[i][i] < 0`；传递闭包可用 bitset 优化到 `O(n^3/64)`（本实现以正确性优先用 bool 矩阵）。

## mst.hpp —— 最小生成树

**功能**：求无向图最小生成树权值（Kruskal / Prim）。

**主要接口**：

```cpp
struct MSTEdge { int u, v; ll w; };   // 命名唯一

ll kruskal(int n, std::vector<MSTEdge>& edges);
ll prim(int n, const std::vector<std::vector<Edge>>& g);
```

- 两者都返回 MST 权值；**图不连通返回 `-1`**。
- `kruskal`：边表输入，内部并查集（`MSTDSU`，自包含）；会修改传入的 `edges`（排序）。
- `prim`：堆优化，邻接表输入（每条无向边在两端各存一次）。

**用法示例**：

```cpp
vector<MSTEdge> edges;
ll w1 = kruskal(n, edges);

vector<vector<Edge>> g(n + 1);
ll w2 = prim(n, g);
```

**复杂度**：Kruskal `O(m log m)`；Prim `O((n + m) log n)`。

**注意事项**：`n == 1` 时 MST 权值为 0；重边、负权边均正确处理。

## topological_sort.hpp —— 拓扑排序

**功能**：对有向无环图求拓扑序（Kahn 算法）。

**主要接口**：

```cpp
std::vector<int> topo_sort(int n, const std::vector<std::vector<int>>& g);
std::vector<int> topo_sort_lex(int n, const std::vector<std::vector<int>>& g);
```

- `topo_sort`：返回一种合法拓扑序；有环返回**空 vector**。
- `topo_sort_lex`：返回**字典序最小**的拓扑序（小顶堆）。

**用法示例**：

```cpp
vector<int> order = topo_sort(n, g);
vector<int> lex   = topo_sort_lex(n, g);
```

**复杂度**：时间 `O(n + m)`，空间 `O(n + m)`。

**注意事项**：返回顶点编号序列；孤立点也会出现在拓扑序中。

## bipartite.hpp —— 二分图判定与最大匹配

**功能**：二分图染色判定 + 匈牙利最大匹配。

**主要接口**：

```cpp
bool is_bipartite(int n, const std::vector<std::vector<int>>& g, std::vector<int>& color);
int  hungarian(int n, int m, const std::vector<std::vector<int>>& adj);
```

- `is_bipartite`：BFS 染色，`color` 输出 0/1；非二分图返回 `false`。
- `hungarian`：左部 `1..n`、右部 `1..m`，`adj[u]` 为左部点 `u` 可匹配的右部点集合；返回最大匹配数。

**用法示例**：

```cpp
vector<int> color;
bool ok = is_bipartite(n, g, color);

int match = hungarian(L, R, adj);
```

**复杂度**：判定 `O(n + m)`；匈牙利 `O(n * 边数)`。

**注意事项（结论）**：最小点覆盖 = 最大匹配；最大独立集 = `n + m - 最大匹配`；最小边覆盖 = 顶点数 - 最大匹配。

## dinic.hpp —— 最大流

**功能**：BFS 分层 + DFS 多路增广 + 当前弧优化的 Dinic 最大流，可求最小割边集。

**主要接口**：

```cpp
class Dinic {
public:
    explicit Dinic(int n);
    void add_edge(int u, int v, ll cap);
    ll maxflow(int s, int t);
    std::vector<std::pair<int,int>> min_cut_edges(int s, int t);
};
```

- `add_edge`：加容量为 `cap` 的有向边 `u -> v`（自动建容量 0 的反向边）。
- `maxflow`：返回 `s` 到 `t` 的最大流。
- `min_cut_edges`：**必须在 `maxflow(s,t)` 之后调用**，返回最小割的原边端点对（从可达集到不可达集、且已饱和的边）。

**用法示例**：

```cpp
Dinic din(4);
din.add_edge(1, 2, 3); din.add_edge(1, 3, 2);
din.add_edge(2, 4, 2); din.add_edge(3, 4, 3);
ll f = din.maxflow(1, 4);
vector<pair<int,int>> cut = din.min_cut_edges(1, 4);
```

**复杂度**：一般图 `O(n^2 m)`，单位容量网络更快。

**注意事项**：顶点编号 `1..n`；容量用 `long long`；DFS 多路增广为递归实现，超大图注意栈空间。

## mcmf.hpp —— 最小费用最大流

**功能**：求最大流中费用最小的方案（最小费用最大流），允许负费用边（无负费用环）。

**主要接口**：

```cpp
class MCMF {
public:
    explicit MCMF(int n);
    void add_edge(int u, int v, ll cap, ll cost);
    std::pair<ll, ll> min_cost_flow(int s, int t);
};
```

- `min_cost_flow` 返回 `{最大流量, 最小总费用}`。

**用法示例**：

```cpp
MCMF mf(4);
mf.add_edge(1, 2, 2, 1);
mf.add_edge(1, 3, 1, 5);
pair<ll,ll> res = mf.min_cost_flow(1, 4);   // {3, 10}（最大流 3，最小费用 10）
```

**复杂度**：上界 `O(F * n * m)`（`F` 为最大流量），实际通常远快。

**注意事项**：图中不能有负费用环；每次 SPFA 找费用最短路并沿路径增广（`pre` 记录路径边）。

## tarjan.hpp —— 强连通分量

**功能**：求有向图的强连通分量（SCC），支持缩点。

**主要接口**：

```cpp
class SCC {
public:
    explicit SCC(int n);
    void add_edge(int u, int v);
    void run();                                  // 加完边后调用
    int count() const;
    const std::vector<int>& id() const;          // id[x] ∈ 1..count
    std::vector<std::vector<int>> build_dag() const;
};
```

**用法示例**：

```cpp
SCC scc(4);
scc.add_edge(1, 2); scc.add_edge(2, 1);
scc.run();
int c = scc.count();
vector<vector<int>> dag = scc.build_dag();
```

**复杂度**：时间 `O(n + m)`，空间 `O(n + m)`。

**注意事项**：`build_dag` 可能含重边（自行去重）；Tarjan 编号为反向拓扑序（编号大的分量在 DAG 中更靠源侧）。

## two_sat.hpp —— 2-SAT

**功能**：判断 n 个布尔变量的一组「或子句」是否可满足，并给出赋值。

**主要接口**：

```cpp
class TwoSAT {
public:
    explicit TwoSAT(int n);                      // n 个变量，编号 1..n
    void add_clause(int a, bool va, int b, bool vb);  // (a==va) OR (b==vb)
    bool solve();
    const std::vector<bool>& assignment() const; // 下标 1..n
};
```

**节点编号约定**：变量 `x` 的真节点 = `2x-1`，假节点 = `2x`，共 `2n` 个点。

**用法示例**：

```cpp
TwoSAT sat(2);
sat.add_clause(1, true,  2, true);   // (x1) OR (x2)
sat.add_clause(1, false, 2, true);   // (¬x1) OR (x2)
bool ok = sat.solve();
const vector<bool>& ans = sat.assignment();
```

**复杂度**：时间 `O(n + m)`，空间 `O(n + m)`。

**注意事项**：内部用 `graph/tarjan.hpp` 的 `SCC` 求解；`assignment()` 需在 `solve()` 返回 true 后调用。

## bridge.hpp —— 割点 / 桥 / 边双连通

**功能**：Tarjan 求割点、桥、边双连通分量。

**主要接口**：

```cpp
std::vector<int> cut_vertices(int n, const std::vector<std::vector<int>>& g);

std::vector<std::pair<int,int>> bridges(int n,
    const std::vector<std::vector<std::pair<int,int>>>& g);   // g[u] = {(v, edge_id)}

class EdgeBCC {
public:
    explicit EdgeBCC(int n);
    void add_edge(int u, int v);
    void run();
    int count() const;
    const std::vector<int>& id() const;   // id[x] ∈ 1..count
};
```

**用法示例**：

```cpp
vector<int> cuts = cut_vertices(n, g);

vector<vector<pair<int,int>>> g2(n + 1);   // 边编号防重边
int eid = 0;
g2[1].push_back({2, eid}); g2[2].push_back({1, eid}); ++eid;
vector<pair<int,int>> br = bridges(n, g2);

EdgeBCC bcc(4);
bcc.add_edge(1, 2); bcc.add_edge(2, 3);
bcc.run();
```

**复杂度**：时间 `O(n + m)`，空间 `O(n + m)`。

**注意事项**：`cut_vertices` 适用简单图（无自环/重边）；`bridges` 与 `EdgeBCC` 用**边编号**正确处理重边（只跳过「来时同一条边」）。

## lca.hpp —— 倍增 LCA 与树上差分

**功能**：倍增法求最近公共祖先、树上距离、k 级祖先；树上差分统计路径覆盖。

**主要接口**：

```cpp
class LCA {
public:
    explicit LCA(int n);
    void add_edge(int u, int v);
    void build(int root = 1);
    int lca(int u, int v);
    int dist(int u, int v);           // 边数距离
    int kth_ancestor(int u, int k);   // 向上 k 级祖先，k 超界返回 0
};

void path_diff_add(std::vector<ll>& diff, int u, int v, int lca_node, int fa_lca, ll w);
std::vector<ll> path_diff_finalize(const std::vector<std::vector<int>>& g,
                                   int root, std::vector<ll> diff);
```

**用法示例**：

```cpp
LCA lca(n);
lca.add_edge(1, 2); lca.add_edge(2, 3);
lca.build(1);
int w = lca.lca(2, 3);

// 点差分统计路径覆盖
vector<ll> diff(n + 1, 0);
int l = lca.lca(u, v), fl = lca.kth_ancestor(l, 1);
path_diff_add(diff, u, v, l, fl, 1);
vector<ll> cnt = path_diff_finalize(tree, 1, diff);
```

**复杂度**：`build` `O(n log n)`；每次查询 `O(log n)`；差分汇总 `O(n)`。

**注意事项**：
- `LOG` 动态计算（`while ((1LL << LOG) <= n)`）；`up` 用 `up[LOG][n+1]` 布局（按层存储，缓存更友好）。
- **点差分**（统计点覆盖）：`diff[u]+=w, diff[v]+=w, diff[lca]-=w, diff[fa(lca)]-=w`（即 `path_diff_add`）。
- **边差分**（统计边覆盖）：`diff[u]+=w, diff[v]+=w, diff[lca]-=2w`；finalize 后 `diff[y]` 表示边 `(fa(y), y)` 的覆盖次数。

## euler_path.hpp —— 欧拉路径 / 欧拉回路

**功能**：求无向图 / 有向图的欧拉路径或回路（Hierholzer 算法），内置存在性检查。

**主要接口**：

```cpp
std::vector<int> euler_path(int n,
    std::vector<std::vector<std::pair<int,int>>> g, bool directed);
```

- `g[u] = {(v, edge_id)}`，`edge_id` 从 0 开始。
- `directed = true` 表示有向图；`false` 表示无向图。
- 返回路径点序列（长度 = 边数 + 1，含起点）；不存在时返回空 vector。

**用法示例**：

```cpp
vector<vector<pair<int,int>>> g(n + 1);
int eid = 0;
g[1].push_back({2, eid}); g[2].push_back({1, eid}); ++eid;
vector<int> path = euler_path(n, g, false);
```

**复杂度**：时间 `O(n + m)`，空间 `O(n + m)`。

**注意事项**：
- 无向图：奇度点数为 0（回路）或 2（路径），且非零度点连通；奇度点恰 2 个时以奇度点为起点。
- 有向图：出入度差条件 + 底图（忽略方向）非零度点连通。
- 无向图重边、自环均正确处理（自环需在 `g[u]` 中存两个相同 `edge_id` 的条目）。
