# 杂项

本分类收录非几何的通用工具：快读快写、随机数、计时与内存、调试输出、位运算。
所有声明都在 `namespace algo` 中；涉及 `ll`/`ull`/`INF`/`EPS` 时引用
`algo/common.hpp`。

编译时使用 `-I include`，头文件自包含。

---

## 1. 快读快写 —— `misc/fastio.hpp`

### 功能

基于 `fread`/`fwrite` 缓冲的整数快速输入输出，比 `scanf`/`printf` 更快。

### 主要接口

```cpp
template<typename T> bool read(T& x);      // 快读整数（int/ll/ull，负数），EOF 返回 false
template<typename T> void write(T x);      // 快写整数（含负数）
void write_char(char c);                   // 输出单个字符
void write_str(const char* s);             // 输出 C 字符串
template<typename T> void println(T x);    // 输出整数并换行
void flush();                              // 刷新输出缓冲
```

### 用法示例

```cpp
#include "misc/fastio.hpp"
using namespace algo;

long long n;
while (read(n)) {          // 读到 EOF 返回 false
    println(n * 2);
}
write_str("done\n");
flush();                   // 程序结束前刷新（省略则由析构自动刷新）
```

### 复杂度

每字节 O(1)；输入/输出缓冲各 `1 << 20` 字节。

### 注意事项

- 不要与 `cin`/`cout`/`scanf`/`printf` 混用；本模块直接操作 `stdin`/`stdout`
  缓冲，混用会导致顺序错乱。若必须混用，先调用 `flush()`，并让 `cin` 解除
  与 stdio 的同步。
- 无符号类型读取接近 `2^64-1` 的极大值时，累加过程可能溢出，建议只读 `< 2^63`。
- 输入须为合法整数。

## 2. 随机数 —— `misc/random.hpp`

### 功能

封装 `std::mt19937_64` 的随机数类：整数/实数随机、向量洗牌。

### 主要接口

```cpp
class Random {
public:
    Random();                              // 随机种子
    explicit Random(ull seed);             // 指定种子（可复现）
    int next_int(int l, int r);            // [l, r]
    ll next_ll(ll l, ll r);                // [l, r]
    double next_real(double l, double r);  // [l, r)
    template<typename T> void shuffle(std::vector<T>& v); // 洗牌
};
```

### 用法示例

```cpp
#include "misc/random.hpp"
using namespace algo;

Random rng;
int a = rng.next_int(1, 100);
long long b = rng.next_ll(1LL, 1000000000000LL);
double d = rng.next_real(0.0, 1.0);
std::vector<int> v = {1, 2, 3, 4, 5};
rng.shuffle(v);
```

### 复杂度

取随机数 O(1)；洗牌 O(n)。

### 注意事项

- 整数区间为闭区间，要求 `l <= r`，否则行为未定义。
- `next_real` 为半开区间 `[l, r)`。
- 默认构造用 `std::random_device` 播种，个别平台退化时退回时钟种子。

## 3. 计时与内存 —— `misc/timer.hpp`

### 功能

基于 `std::chrono::steady_clock` 的计时器，以及 Linux 下的进程内存统计。

### 主要接口

```cpp
class Timer {
public:
    Timer();                     // 构造即开始计时
    double elapsed_ms() const;   // 经过毫秒
    double elapsed_sec() const;  // 经过秒
    void reset();                // 重新计时
};

ll memory_usage_kb();            // 进程内存占用（KB），仅 Linux
```

### 用法示例

```cpp
#include "misc/timer.hpp"
using namespace algo;

Timer t;
// ... 被测代码 ...
double ms = t.elapsed_ms();
t.reset();
long long kb = memory_usage_kb();  // Linux 返回 RSS KB，其他平台 -1
```

### 复杂度

O(1)。

### 注意事项

- `steady_clock` 单调递增，不受系统时间调整影响。
- `memory_usage_kb` 仅在 Linux（`__linux__`）读取 `/proc/self/statm` 实现，
  其他平台返回 `-1`；不依赖 `windows.h`，避免宏冲突。

## 4. 调试输出 —— `misc/debug.hpp`

### 功能

宏 `ALGO_DBG(...)` 在定义 `ALGO_DEBUG` 时向 stderr 打印"变量名 = 值"，
支持多参数，并对 `vector`/`map`/`set`/`pair`/`string` 提供专门打印；
未定义 `ALGO_DEBUG` 时零开销展开为空。

### 主要接口

```cpp
// 宏（不是函数）
ALGO_DBG(a, b, c);   // 定义 ALGO_DEBUG 时输出，否则展开为 ((void)0)

// 内部辅助（供重载/扩展）
template<typename T> void dbg_print_one(const char* name, const T& v);
template<typename T> void dbg_print_value(const T& v);
```

### 用法示例

```cpp
#define ALGO_DEBUG               // 开启调试（或编译加 -DALGO_DEBUG）
#include "misc/debug.hpp"

int a = 3;
std::vector<int> v = {1, 2, 3};
std::map<std::string, int> m = {{"x", 1}};
ALGO_DBG(a, v, m);   // [file.cpp:8] a = 3, v = [1, 2, 3], m = {"x": 1}
```

### 复杂度

与打印内容规模成正比。

### 注意事项

- 在 `#include "misc/debug.hpp"` 之前 `#define ALGO_DEBUG`（或编译加 `-DALGO_DEBUG`）。
- 未定义 `ALGO_DEBUG` 时展开为 `((void)0)`，不引用、不求值参数，零开销。
- `ALGO_DBG` 至少需要 1 个参数。
- 泛型类型需支持 `operator<<` 才能打印。

## 5. 位运算工具 —— `misc/bit.hpp`

### 功能

`lowbit`、`popcount`、`msb_index`、子集枚举、Gosper's hack。

### 主要接口

```cpp
int lowbit(int x);                     // 最低位 1
ll lowbit_ll(ll x);                    // long long 版本
int popcount(ll x);                    // 二进制中 1 的个数
int msb_index(ll x);                   // 最高位 1 的下标（0-based），x<=0 返回 -1
std::vector<int> enumerate_subsets(int mask); // mask 的所有子集（含 0）
ll next_combination(ll x);             // Gosper's hack，x=0 返回 0
```

### 用法示例

```cpp
#include "misc/bit.hpp"
using namespace algo;

int lb = lowbit(12);                       // 4
int pc = popcount(12LL);                   // 2
int msb = msb_index(12LL);                 // 3
std::vector<int> subs = enumerate_subsets(0b101); // {5, 4, 1, 0}
long long nx = next_combination(0b1011);   // 下一个二进制 1 个数相同且更大的数
```

### 复杂度

`lowbit`/`next_combination` O(1)；`popcount` O(1)（SWAR 或内置）；
`msb_index` O(64)（或内置 O(1)）；`enumerate_subsets` O(2^k)。

### 注意事项

- `popcount` 在 `__GNUC__`（含 Clang）用 `__builtin_popcountll`，否则手写 SWAR，
  MSVC/GCC/Clang 均可编译。
- `msb_index` 只对非负整数有意义，0 和负数返回 -1。
- `next_combination` 输入应为可用 `long long` 表示的位掩码（建议 `< 2^63`）。
