# 基础算法

本分类收录通用的**基础算法板子**：二分、三分、排序与选择、离散化、莫队、
折半搜索、LIS/LCS。全部为头文件实现（header-only），位于 `include/algo/` 下，
统一放在 `namespace algo` 内，依赖 C++17 标准库。

约定：整数默认使用 `long long`（别名 `algo::ll`，定义于 `algo/common.hpp`）；
所有区间若无特殊说明均为**闭区间**；数组下标从 0 开始。

---

## 1. 二分 —— `algo/binary_search.hpp`

**功能**：函数式二分，把判定条件抽象成单调谓词 `pred(mid)`，在闭区间上求分界点。
适用于二分答案（最大值最小化 / 最小值最大化）、单调函数零点等。

**主要接口**：

```cpp
// 找第一个使 pred(mid) 为 true 的位置（pred 单调 false→true）
template<typename Pred>
int lower_bound_func(int l, int r, Pred pred);

// 找最后一个使 pred(mid) 为 true 的位置（pred 单调 true→false）
template<typename Pred>
int upper_bound_func(int l, int r, Pred pred);

// 实数二分：固定迭代次数，求 pred(mid)==true 的分界点
template<typename Pred>
double binary_search_real(double l, double r, Pred pred, int iter = 100);
```

**用法示例**：

```cpp
// 求最后一个满足 a[i] <= x 的下标（a 升序）
int pos = algo::upper_bound_func(0, n - 1, [&](int mid){ return a[mid] <= x; });
// 找不到返回 -1

// 求第一个满足 a[i] >= x 的下标
int pos = algo::lower_bound_func(0, n - 1, [&](int mid){ return a[mid] >= x; });
// 找不到返回 n

// 实数二分求单调递增函数 f 的零点
double x = algo::binary_search_real(-1e9, 1e9, [&](double mid){ return f(mid) >= 0.0; });
```

**复杂度**：整数 O(log(r-l+1)) 次谓词调用；实数 O(iter)。空间 O(1)。

**注意事项**：谓词必须单调；整数版空区间（l>r）按"找不到"返回；mid 用防溢出写法；
实数版误差约 (r-l)/2^iter。

## 2. 三分 —— `algo/three_point.hpp`

**功能**：在单峰函数上求极值点（返回自变量位置）。求极大值时对 f 取负再求极小。

**主要接口**：

```cpp
// 实数域三分求单谷函数极小值点
template<typename F>
double ternary_min(double l, double r, F f, int iter = 200);

// 整数域三分求单谷函数极小值点
template<typename F>
algo::ll ternary_min_int(algo::ll l, algo::ll r, F f);
```

**用法示例**：

```cpp
// f(x) = (x-3)^2 极小值点 ≈ 3
double x = algo::ternary_min(-100.0, 100.0, [](double x){ return (x-3.0)*(x-3.0); });

// 整数域 f(x)=x*x 极小值点 0
long long y = algo::ternary_min_int(-10LL, 10LL, [](long long x){ return x*x; });

// 极大值：取负
double xmax = algo::ternary_min(-10.0, 10.0, [](double x){ return -(x-2.0)*(x-2.0); });
```

**复杂度**：实数 O(iter)；整数每次缩到约 2/3，O(log n)。空间 O(1)。

**注意事项**：函数须单峰；整数版最后暴力检查剩余至多 3 个点；要求 l <= r；
注意 f 内部乘法溢出。

## 3. 排序与选择 —— `algo/sort.hpp`

**功能**：归并排序、逆序对计数、快速排序、第 k 小选择。

**主要接口**：

```cpp
// 稳定归并排序（原地，O(n) 辅助空间）
template<typename T> void merge_sort(std::vector<T>& a);

// 求逆序对数量（不修改原数组，返回 long long）
template<typename T> algo::ll inversion_count(const std::vector<T>& a);

// 随机基准快速排序（闭区间 [l, r]）
template<typename T> void quick_sort(std::vector<T>& a, int l, int r);

// 第 k 小（k 从 0 开始），期望 O(n)，会打乱数组
template<typename T> T quick_select(std::vector<T>& a, int k);
```

**用法示例**：

```cpp
std::vector<int> a = {3, 1, 4, 1, 5};
algo::merge_sort(a);                       // 升序
long long inv = algo::inversion_count(a);  // 逆序对，a 不变
algo::quick_sort(a, 0, (int)a.size() - 1); // 快速排序
int kth = algo::quick_select(a, 2);        // 第 3 小，a 被打乱
```

**复杂度**：merge_sort / inversion_count 均为 O(n log n) 时间、O(n) 空间；
quick_sort / quick_select 期望 O(n log n) / O(n)，递归栈 O(log n)。

**注意事项**：quick_select 前置条件 0 <= k < n 且 a 非空；随机基准用 `std::rand`
（必要时先 `srand`）；逆序对数量可能超 int，返回 long long。

## 4. 离散化 —— `algo/discretize.hpp`

**功能**：把数值范围很大的值（可含负数）压缩成 0-based 排名，供值域建树 / 坐标压缩。

**主要接口**：

```cpp
template<typename T>
class Discrete {
public:
    Discrete();
    void build(const std::vector<T>& a);   // 去重 + 排序
    int rank_of(const T& v) const;         // 0-based 排名，不存在返回 -1
    const std::vector<T>& values() const;  // 去重后的有序值（还原用）
    int size() const;                      // 去重后元素个数
};
```

**用法示例**：

```cpp
std::vector<long long> a = {10, -3, 10, 5, -3, 0};
algo::Discrete<long long> disc;
disc.build(a);
for (long long& x : a) x = disc.rank_of(x);  // {3, 0, 3, 2, 0, 1}
// disc.values()[i] 即排名 i 对应的原始值
```

**复杂度**：build O(n log n)；rank_of O(log n)。空间 O(n)。

**注意事项**：T 需支持 `<` 与 `==`；重复值被去重；空数组 size()=0 且 rank_of 恒 -1。

## 5. 莫队 —— `algo/mo_algorithm.hpp`

**功能**：离线区间查询。当相邻区间答案可 O(1) 扩展时，排序询问后用双指针滑动，
把朴素 O(n·m) 降到约 O((n+m)·sqrt(m))。典型：区间不同数个数、区间众数。

**主要接口**：

```cpp
struct MoQuery { int l, r, id; };  // 0-based 闭区间

template<typename Add, typename Del, typename Get>
std::vector<algo::ll> mo_solve(int n, std::vector<MoQuery> qs,
                               Add add, Del del, Get get);
// add(idx)/del(idx)：加入/删除下标 idx 的元素；get()：返回当前答案
```

**用法示例（区间不同数个数）**：

```cpp
int n = 6;
std::vector<int> a = {1, 2, 1, 3, 2, 1};
std::vector<algo::MoQuery> qs = { {0,3,0}, {1,4,1}, {2,5,2} };
std::vector<int> cnt(4, 0);
long long cur = 0;
auto add = [&](int idx){ if (++cnt[a[idx]] == 1) ++cur; };
auto del = [&](int idx){ if (--cnt[a[idx]] == 0) --cur; };
auto get = [&](){ return cur; };
std::vector<long long> ans = algo::mo_solve(n, qs, add, del, get);  // {3,3,3}
```

**复杂度**：块大小 B ≈ n/sqrt(m)，总 O(m log m + (n+m)·B)，近似 O((n+m)·sqrt(m))；
空间 O(m)。

**注意事项**：查询须满足 0 <= l <= r < n；初始区间为空（cur_l=0, cur_r=-1）；
qs 为空直接返回空数组；排序采用奇偶优化（奇数块 r 降序）；指针先扩张后收缩。

## 6. 折半搜索 —— `algo/meet_in_middle.hpp`

**功能**：把 2^n 枚举拆成两半分别枚举再合并，降到约 2^(n/2)。提供子集和生成与
"最接近 target 的子集和"。

**主要接口**：

```cpp
// 所有子集和（含空集 0），O(2^n)
template<typename T> std::vector<T> subset_sums(const std::vector<T>& a);

// 折半搜索：最接近 target 的子集和（含负数正确）
template<typename T> T closest_subset_sum(const std::vector<T>& a, T target);
```

**用法示例**：

```cpp
std::vector<long long> a = {5, -7, 3, 5};
long long ans = algo::closest_subset_sum(a, 1LL);        // 1（= 5-7+3）
std::vector<long long> sums = algo::subset_sums(a);      // 16 个，含 0
```

**复杂度**：subset_sums O(2^n)；closest_subset_sum O(2^(n/2) log 2^(n/2))。
空间均为 O(2^(n/2))。

**注意事项**：subset_sums 适用 n <= 20；closest_subset_sum 适用 n <= 40；
支持负数（合并时用 lower_bound 并检查前驱）；空数组返回 0。

## 7. LIS / LCS —— `algo/lis_lcs.hpp`

**功能**：最长上升（或不下降）子序列长度、最长公共子序列长度。

**主要接口**：

```cpp
// 最长上升子序列长度；strict=false 时求最长不下降子序列
template<typename T> int lis(const std::vector<T>& a, bool strict = true);

// 最长公共子序列长度（字符串）
int lcs(const std::string& a, const std::string& b);
```

**用法示例**：

```cpp
std::vector<int> a = {2, 1, 5, 3, 6, 4, 8, 9, 7};
int len1 = algo::lis(a);           // 5（严格上升，如 1,3,6,8,9）
int len2 = algo::lis(a, false);    // 不下降长度
int len3 = algo::lcs("abcde", "ace");  // 3
```

**复杂度**：lis O(n log n)、O(n)；lcs O(n·m)、O(n·m)。

**注意事项**：lis 用 tails 数组（严格用 lower_bound、非严格用 upper_bound）；
只返回长度，要还原需另存前驱；lcs 可用滚动数组优化到 O(min(n,m))；空序列返回 0。
