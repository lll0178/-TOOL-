# 数学（Math）

数学分类板子，全部位于 `include/math/` 目录，统一使用 `namespace algo`。
整数默认类型为 `long long`（别名 `ll`，见 `algo/common.hpp`）。

库内依赖关系（均通过 `#include "math/xxx.hpp"`）：

```
fastpow.hpp   （qmul / qpow，最基础）
gcd.hpp       （gcd / lcm / exgcd / linear_equation）
prime.hpp     → fastpow.hpp
euler_phi.hpp
mobius.hpp
inverse.hpp   → fastpow.hpp + gcd.hpp
crt.hpp       → fastpow.hpp + gcd.hpp
linear_basis.hpp
gauss.hpp     → inverse.hpp
matrix.hpp
combinatorics.hpp → fastpow.hpp
modint.hpp
fft.hpp
ntt.hpp       → fastpow.hpp
bsgs.hpp      → fastpow.hpp
bigint.hpp
```

## 1. fastpow.hpp —— 快速幂 / 快速乘

- **功能**：防溢出的模意义快速乘 `qmul` 与快速幂 `qpow`。
- **主要接口**：
  - `ll qmul(ll a, ll b, ll mod)`：返回 `(a*b) % mod`，二进制拆分防溢出；负数先转正取模。
  - `ll qpow(ll a, ll b, ll mod)`：返回 `(a^b) % mod`，`b >= 0`，内部乘法用 `qmul`。
- **用法示例**：

```cpp
#include "math/fastpow.hpp"
ll x = algo::qmul(1000000000000000000LL, 1000000000000000000LL, 1000000007);
ll y = algo::qpow(2, 60, 1000000007);
```

- **复杂度**：`O(log b)`，空间 `O(1)`。
- **注意事项**：`mod` 必须为正；`b` 必须非负；`qmul` 内部用 `unsigned long long`
  加法，支持 `mod` 高达 `LLONG_MAX`。

## 2. gcd.hpp —— 最大公约数 / 扩展欧几里得 / 不定方程

- **功能**：最大公约数、最小公倍数、扩展欧几里得、线性不定方程。
- **主要接口**：
  - `ll gcd(ll a, ll b)`：返回非负最大公约数（兼容负数）。
  - `ll lcm(ll a, ll b)`：`a / gcd * b`（先除后乘防溢出）。
  - `ll exgcd(ll a, ll b, ll& x, ll& y)`：返回 `gcd(a,b)`，输出 `ax + by = gcd` 特解。
  - `bool linear_equation(ll a, ll b, ll c, ll& x, ll& y)`：解 `ax + by = c`，有解返回 `true`。
- **用法示例**：

```cpp
#include "math/gcd.hpp"
ll x, y;
bool ok = algo::linear_equation(3, 5, 7, x, y);  // 3x + 5y = 7
```

- **复杂度**：`O(log min(|a|,|b|))`，空间 `O(1)`。
- **注意事项**：`exgcd` 假定 `a,b` 非负；通解 `x = x0 + (b/g)t, y = y0 - (a/g)t`；
  最小非负 `x` 用 `step = b/g`，`x = (x0 % step + step) % step`。

## 3. prime.hpp —— 素数

- **功能**：素数筛、Miller-Rabin 素性测试、Pollard-Rho 质因数分解。
- **主要接口**：
  - `vector<bool> sieve(int n)`：埃氏筛，返回 `is_prime[0..n]`。
  - `vector<int> euler_sieve(int n)`：欧拉线性筛，返回 `1..n` 素数表。
  - `bool is_prime(ll n)`：Miller-Rabin，固定基底 `{2,...,37}`，`n < 2^64` 确定。
  - `vector<pair<ll,ll>> factorize(ll n)`：质因数分解，返回 `{质因子, 次数}` 升序。
- **用法示例**：

```cpp
#include "math/prime.hpp"
bool p = algo::is_prime(1000000007LL);
auto fac = algo::factorize(600851475143LL);
```

- **复杂度**：埃氏筛 `O(n log log n)`，欧拉筛 `O(n)`；`is_prime` `O(k log^2 n)`；
  `factorize` 期望 `O(n^{1/4})`。
- **注意事项**：`factorize(1)` 返回空；`is_prime(n<2)` 返回 `false`；先试除 `<=100` 小素数。

## 4. euler_phi.hpp —— 欧拉函数

- **功能**：单点欧拉函数与线性筛 φ 表。
- **主要接口**：
  - `ll phi(ll n)`：`O(sqrt n)` 试除分解求 `φ(n)`。
  - `vector<int> phi_table(int n)`：线性筛求 `φ(1..n)`。
- **用法示例**：

```cpp
#include "math/euler_phi.hpp"
ll v = algo::phi(12);           // 4
auto tab = algo::phi_table(10); // tab[6] == 2
```

- **复杂度**：`phi` `O(sqrt n)`；`phi_table` `O(n)`。
- **注意事项**：`phi(n)` 在 `n<1` 时返回 0；`φ(1)=1`。

---

## 5. mobius.hpp —— 莫比乌斯函数与整除分块

- **功能**：线性筛莫比乌斯函数、整除分块。
- **主要接口**：
  - `vector<int> mobius_table(int n)`：求 `μ(1..n)`。
  - `vector<pair<ll,ll>> floor_blocks(ll n)`：返回所有 `floor(n/i)` 相等的段 `[l,r]`。
- **用法示例**：

```cpp
#include "math/mobius.hpp"
auto mu = algo::mobius_table(100);
for (auto& seg : algo::floor_blocks(100)) {
    // [seg.first, seg.second] 内 floor(100/i) 相等
}
```

- **复杂度**：`mobius_table` `O(n)`；`floor_blocks` `O(sqrt n)`。
- **注意事项**：头文件注释含莫比乌斯反演公式与 `gcd=1` 计数、`Σ floor(n/i)` 的
  `O(sqrt n)` 加速示例。

## 6. inverse.hpp —— 逆元

- **功能**：单点逆元（费马 / 扩欧）、逆元表、阶乘与阶乘逆元表。
- **主要接口**：
  - `ll inv_fermat(ll a, ll mod)`：费马小定理（`mod` 质数）。
  - `ll inv_exgcd(ll a, ll mod)`：扩欧求逆（`a` 与 `mod` 互质）。
  - `vector<ll> inv_table(int n, ll mod)`：`O(n)` 递推 `1..n` 逆元。
  - `vector<ll> fact_table(int n, ll mod)` / `inv_fact_table(int n, ll mod)`。
- **用法示例**：

```cpp
#include "math/inverse.hpp"
ll iv = algo::inv_fermat(3, 1000000007);
auto inv = algo::inv_table(100000, 1000000007);
```

- **复杂度**：单点 `O(log mod)`；表 `O(n)`。
- **注意事项**：`inv_table` 要求 `mod` 质数且 `mod > n`；`fact_table`/`inv_fact_table`
  要求 `mod` 质数且 `n < mod`。

---

## 7. crt.hpp —— 中国剩余定理

- **功能**：CRT 与扩展 CRT。
- **主要接口**：
  - `ll crt(const vector<ll>& a, const vector<ll>& m)`：`m` 两两互质，返回最小非负解。
  - `ll excrt(const vector<ll>& a, const vector<ll>& m)`：`m` 可不互质，两两合并，无解返回 `-1`。
- **用法示例**：

```cpp
#include "math/crt.hpp"
ll x = algo::crt({2, 3, 1}, {3, 5, 7});   // 23
ll y = algo::excrt({2, 3}, {4, 6});       // -1（无解）
```

- **复杂度**：`O(n log M)`。
- **注意事项**：`m[i]` 为正；`crt` 的 `M = ∏m` 与 `excrt` 的每一步 `lcm` 均须在 `ll` 范围内。

## 8. linear_basis.hpp —— 异或线性基

- **功能**：异或线性基（61 位）。
- **主要接口**：
  - `void insert(ll x)`；`bool can(ll x) const`；`ll max_xor() const`；
    `ll kth(ll k) const`；`int size() const`。
- **用法示例**：

```cpp
#include "math/linear_basis.hpp"
algo::LinearBasis lb;
lb.insert(5); lb.insert(6); lb.insert(9);
ll mx = lb.max_xor();
ll k1 = lb.kth(1);
```

- **复杂度**：`insert/can/max_xor` `O(61)`；`kth` `O(61^2)`。
- **注意事项**：`kth` 的 `k` 从 1 开始；若插入失败过（可异或出 0），`kth(1)=0`（内部 `k--`）。

## 9. gauss.hpp —— 高斯消元

- **功能**：浮点 / 模质数消元解线性方程组，模意义行列式。
- **主要接口**：
  - `vector<double> gauss(vector<vector<double>> a)`：`a` 为 `n x (n+1)` 增广矩阵。
  - `vector<ll> gauss_mod(vector<vector<ll>> a, ll mod)`：模质数消元。
  - `ll determinant_mod(vector<vector<ll>> a, ll mod)`：模意义行列式。
- **用法示例**：

```cpp
#include "math/gauss.hpp"
std::vector<std::vector<double>> A = {{2,1,-1,8}, {-3,-1,2,-11}, {-2,1,2,-3}};
auto x = algo::gauss(A);  // 唯一解；无解/无穷解返回空
```

- **复杂度**：`O(n^3)`。
- **注意事项**：无解或无穷解返回空 vector；`gauss_mod`/`determinant_mod` 要求 `mod` 质数。

---

## 10. matrix.hpp —— 矩阵与矩阵快速幂

- **功能**：动态矩阵（带模数），乘法与快速幂。
- **主要接口**：
  - `Matrix(int n, ll mod)` / `Matrix(int n, int m, ll mod)`；`static Matrix unit(int n, ll mod)`；
    `ll& at(int i, int j)`；`Matrix operator*(const Matrix&) const`；`Matrix pow(ll e) const`；
    `rows()/cols()/mod()`。
- **用法示例**（斐波那契）：

```cpp
#include "math/matrix.hpp"
algo::Matrix A(2, 2, mod);
A.at(0,0)=1; A.at(0,1)=1; A.at(1,0)=1; A.at(1,1)=0;
ll fn = A.pow(n).at(0, 1);  // F(n)
```

- **复杂度**：乘法 `O(n*m*p)`；`pow` `O(n^3 log e)`。
- **注意事项**：`pow` 要求方阵；元素请保持在 `[0, mod)` 内。

## 11. combinatorics.hpp —— 组合数学

- **功能**：组合数、Lucas、错排、卡特兰、第二类斯特林数。
- **主要接口**：
  - `class Comb { Comb(int max_n, ll mod); ll C(int n,int k); ll A(int n,int k);
    ll factorial(int n); ll inv_factorial(int n); }`
  - `ll lucas(ll n, ll k, ll p)`；`ll derangement(int n, ll mod)`；
    `ll catalan(int n, ll mod)`；`vector<vector<ll>> stirling2(int n, ll mod)`。
- **用法示例**：

```cpp
#include "math/combinatorics.hpp"
algo::Comb comb(100000, 1000000007);
ll c = comb.C(10, 3);
auto S = algo::stirling2(5, 1000000007);  // S[5][2]
```

- **复杂度**：`Comb` 预处理 `O(max_n)` 查询 `O(1)`；`lucas` `O(p + log_p(n) log p)`；
  `derangement/catalan` `O(n)`；`stirling2` `O(n^2)`。
- **注意事项**：`Comb` 要求 `mod` 质数且 `max_n < mod`；`lucas` 要求 `p` 质数且不宜太大；
  `catalan` 要求 `n+1` 不被 `mod` 整除。

## 12. modint.hpp —— 模数类

- **功能**：编译期模数类 `ModInt<MOD>`，自动取模与负数修正。
- **主要接口**：
  - `ModInt(ll v = 0)`；`+ - * /` 及复合赋值；取负；前置/后置 `++ --`；`== !=`；
    `operator ll()`（到 `ll` 隐式转换）；`>> <<`；`friend pow(ModInt, ll)`。
- **用法示例**：

```cpp
#include "math/modint.hpp"
using Mint = algo::ModInt<1000000007>;
Mint a = 5, b = 2;
Mint c = a / b;
Mint d = algo::pow(a, 10);
```

- **复杂度**：`+ - *` `O(1)`；`/` `O(log MOD)`。
- **注意事项**：除法用费马小定理（`MOD` 质数）；`MOD <= 2e9` 时乘法不溢出 `ll`。

## 13. fft.hpp —— FFT 卷积

- **功能**：复数 FFT 卷积。
- **主要接口**：
  - `void fft(vector<complex<double>>& a, bool invert)`：迭代 FFT。
  - `vector<ll> convolution(const vector<ll>& a, const vector<ll>& b)`：结果 round 到 `ll`。
- **用法示例**：

```cpp
#include "math/fft.hpp"
std::vector<long long> a = {1,2,3}, b = {4,5};
auto c = algo::convolution(a, b);  // {4,13,22,15}
```

- **复杂度**：`O(n log n)`。
- **注意事项**：浮点误差，值域大（如 `>1e14`）时 round 可能不准，建议改用 NTT。

---

## 14. ntt.hpp —— NTT 与多项式求逆

- **功能**：NTT 卷积与多项式求逆。
- **主要接口**：
  - `template<int MOD, int G> struct NTT { static vector<ll> convolution(const vector<ll>&, const vector<ll>&); }`
  - `vector<ll> poly_inv(const vector<ll>& a, int n, ll mod)`：返回 `a` 的逆前 `n` 项。
- **用法示例**：

```cpp
#include "math/ntt.hpp"
auto c = algo::NTT<998244353, 3>::convolution({1,2,3}, {4,5});
auto inv = algo::poly_inv({1,1,1}, 5, 998244353);
```

- **复杂度**：`O(n log n)`。
- **注意事项**：`MOD` 为 NTT 友好质数（如 `998244353`），`G` 为其原根；`poly_inv` 固定用
  `NTT<998244353,3>`，`mod` 应传 `998244353`，`a[0]` 非零。

---

## 15. bsgs.hpp —— BSGS 离散对数

- **功能**：解 `a^x ≡ b (mod p)`，`p` 为质数。
- **主要接口**：`ll bsgs(ll a, ll b, ll mod)`：返回最小非负 `x`，无解 `-1`。
- **用法示例**：

```cpp
#include "math/bsgs.hpp"
ll x = algo::bsgs(2, 8, 13);  // 3
```

- **复杂度**：`O(sqrt p)`，空间 `O(sqrt p)`。
- **注意事项**：`b ≡ 1` 返回 0；`a ≡ 0` 时特判；`p` 过大（`>1e7`）时哈希表过大。

---

## 16. bigint.hpp —— 高精度整数

- **功能**：非负高精度整数（`vector<int>` 低位在前）。
- **主要接口**：
  - 构造：默认 0、`BigInt(ll)`、`BigInt(const string&)`（去前导零）。
  - 比较全套；`+ - * / %` 及 `+ - * %` 复合赋值；`to_string()`；`is_zero()`；`<< >>`。
- **用法示例**：

```cpp
#include "math/bigint.hpp"
algo::BigInt a("12345678901234567890"), b("9876543210");
algo::BigInt c = a * b;
std::cout << c.to_string() << '\n';
```

- **复杂度**：加减 `O(n)`；乘 `O(n*m)`（朴素）；除/取模 `O(n*m)`（长除法）。
- **注意事项**：仅非负；减法要求 `a >= b`（assert）；除零 assert；乘法可换 FFT 优化。
