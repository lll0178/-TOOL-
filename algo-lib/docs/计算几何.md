# 计算几何

本分类收录二维计算几何板子。所有类型与函数都位于 `namespace algo` 中，
浮点比较统一使用 `algo::EPS`（1e-9），判零请用 `algo::sgn`。

基础依赖关系：

- `point.hpp` 是基础（定义 `Point` 与 `sgn`/`cross`/`dot`/`polar_less`）。
- `line.hpp` 依赖 `point.hpp`。
- `polygon.hpp` 依赖 `point.hpp` 与 `line.hpp`（`point_in_polygon` 用到 `on_segment`）。
- `convex_hull.hpp`、`rotating_calipers.hpp` 依赖 `point.hpp`。
- `circle.hpp` 依赖 `point.hpp` 与 `line.hpp`。

编译时使用 `-I include`，头文件自包含。

---

## 1. 点与向量 —— `geometry/point.hpp`

### 功能

二维点/向量的基础类型与操作：向量加减、标量乘除、叉积、点积、长度、
单位化、旋转、极角、排序比较、eps 相等比较，以及符号函数与极角排序。

### 主要接口

```cpp
struct Point {
    double x, y;
    Point();                      // (0, 0)
    Point(double x, double y);
    Point operator+(const Point& o) const;   // 向量加
    Point operator-(const Point& o) const;   // 向量减
    Point operator*(double k) const;         // 标量乘
    Point operator/(double k) const;         // 标量除
    double cross(const Point& a, const Point& b) const; // (a-this)×(b-this)
    double dot(const Point& a) const;        // this·a
    double len() const;                      // 模长
    Point normalized() const;                // 单位向量
    Point rotated(double ang) const;         // 逆时针旋转 ang 弧度
    double polar() const;                    // atan2(y, x)
    bool operator<(const Point& o) const;    // x 后 y（精确，严格弱序）
    bool operator==(const Point& o) const;   // eps 比较
};

int sgn(double x);                            // -1 / 0 / 1
double cross(const Point& a, const Point& b); // a×b
double dot(const Point& a, const Point& b);   // a·b
bool polar_less(const Point& a, const Point& b); // 极角排序比较器
```

### 用法示例

```cpp
#include "geometry/point.hpp"
using algo::Point;

Point a(0, 0), b(3, 4);
double d = (b - a).len();                  // 5
Point u = (b - a).normalized();            // (0.6, 0.8)
Point r = b.rotated(acos(-1.0) / 2);       // 逆时针转 90°
int side = algo::sgn(algo::cross(b, Point(1, 0))); // b 在 x 轴哪一侧
```

### 复杂度

所有操作 O(1)。

### 注意事项

- 成员 `cross(a, b)` 以 `*this` 为参考点，返回 `(a-*this)×(b-*this)`；
  两个向量的叉积用自由函数 `algo::cross(a, b)`。
- `operator<` 是精确比较（保证 `std::sort` 安全）；`operator==` 是 eps 比较，
  eps 相等不满足传递性，只用于近似去重。
- `polar_less` 按象限（逆时针 0→3）、再按叉积、最后按长度排序，是严格弱序。

## 2. 直线与线段 —— `geometry/line.hpp`

### 功能

直线/线段类型与点-线段关系：点在线段上、线段相交、直线交点、点到直线/线段
距离、点在直线上的投影。

### 主要接口

```cpp
struct Line { Point a, b; };

bool on_segment(const Point& p, const Point& a, const Point& b);   // p 在线段上（含端点）
bool segments_intersect(const Point& a, const Point& b,
                        const Point& c, const Point& d);           // 两线段相交
Point line_intersection(const Line& l1, const Line& l2);           // 直线交点（不平行）
double point_line_dist(const Point& p, const Line& l);             // 点到直线距离
double point_segment_dist(const Point& p, const Point& a, const Point& b); // 点到线段距离
Point projection(const Point& p, const Line& l);                   // 点在直线上的投影
```

### 用法示例

```cpp
#include "geometry/line.hpp"
using namespace algo;

Line l1(Point(0, 0), Point(1, 1));
Line l2(Point(0, 1), Point(1, 0));
if (segments_intersect(l1.a, l1.b, l2.a, l2.b)) {
    Point p = line_intersection(l1, l2);   // (0.5, 0.5)
}
double h = point_segment_dist(Point(2, 1), Point(0, 0), Point(1, 1));
```

### 复杂度

所有操作 O(1)。

### 注意事项

- `line_intersection` 要求两直线不平行（`sgn(cross(l1.b-l1.a, l2.b-l2.a)) != 0`），
  否则除零；调用前自行判断。
- `segments_intersect` 覆盖规范相交与端点/共线相交。

## 3. 多边形 —— `geometry/polygon.hpp`

### 功能

多边形面积（叉积法）、点在多边形内判定（射线法）、多边形重心（三角剖分加权）。

### 主要接口

```cpp
double polygon_area(const std::vector<Point>& p);             // 面积（绝对值）
int point_in_polygon(const Point& p, const std::vector<Point>& poly); // 1内/0外/2边上
Point polygon_centroid(const std::vector<Point>& p);         // 重心
```

### 用法示例

```cpp
#include "geometry/polygon.hpp"
using namespace algo;

std::vector<Point> poly = {Point(0,0), Point(2,0), Point(2,2), Point(0,2)};
double area = polygon_area(poly);                 // 4
int w = point_in_polygon(Point(1,1), poly);       // 1
int w2 = point_in_polygon(Point(0,1), poly);      // 2（边上）
Point g = polygon_centroid(poly);                 // (1,1)
```

### 复杂度

三者均为 O(n)，空间 O(1)。

### 注意事项

- 顶点须按顺/逆时针顺序给出；`polygon_area` 返回绝对值，与方向无关。
- `point_in_polygon` 已处理 n=0/1/2 的退化情况。
- 重心对退化多边形（面积为 0）退化为顶点算术平均。

## 4. 凸包 —— `geometry/convex_hull.hpp`

### 功能

Andrew 单调链求点集凸包；凸包周长。

### 主要接口

```cpp
std::vector<Point> convex_hull(std::vector<Point> pts); // 逆时针凸包，不含共线中间点
double convex_perimeter(const std::vector<Point>& hull); // 凸包周长
```

### 用法示例

```cpp
#include "geometry/convex_hull.hpp"
using namespace algo;

std::vector<Point> pts = {Point(0,0), Point(1,1), Point(2,0), Point(1,0)};
std::vector<Point> hull = convex_hull(pts);   // (0,0),(2,0),(1,1)
double per = convex_perimeter(hull);
```

### 复杂度

`convex_hull` O(n log n)；`convex_perimeter` O(n)。

### 注意事项

- 先按 (x, y) 排序并 eps 去重；返回逆时针凸包顶点，不含共线中间点。
- 去重后点数 < 3 时返回去重后的全部点（单点/两点/全共线均如此）。

## 5. 旋转卡壳 —— `geometry/rotating_calipers.hpp`

### 功能

旋转卡壳求凸包直径（最远点对距离）。

### 主要接口

```cpp
double convex_diameter(const std::vector<Point>& hull); // 直径距离值
```

### 用法示例

```cpp
#include "geometry/rotating_calipers.hpp"
#include "geometry/convex_hull.hpp"
using namespace algo;

std::vector<Point> hull = convex_hull(pts);
double d = convex_diameter(hull);
```

### 复杂度

O(n)。

### 注意事项

- 输入必须是凸包顶点：逆时针、无重复点（直接使用 `convex_hull` 的输出即可）。
- n ≤ 2 的退化凸包已特殊处理。

## 6. 圆 —— `geometry/circle.hpp`

### 功能

圆与直线/圆的交点、点到圆的切点、最小圆覆盖（随机增量法）。

### 主要接口

```cpp
struct Circle { Point c; double r; };

std::vector<Point> circle_line_intersection(const Circle& c, const Line& l);   // 0/1/2 个
std::vector<Point> circle_circle_intersection(const Circle& c1, const Circle& c2); // 0/1/2 个
std::vector<Point> tangent_points(const Point& p, const Circle& c);            // 点到圆的切点
Circle min_circle_cover(std::vector<Point> pts);                               // 最小圆覆盖
```

内部辅助（命名唯一，供最小圆覆盖使用）：

```cpp
Circle circumcircle(const Point& a, const Point& b, const Point& c); // 三点外接圆
```

### 用法示例

```cpp
#include "geometry/circle.hpp"
using namespace algo;

Circle c(Point(0, 0), 1.0);
Line l(Point(-2, 0), Point(2, 0));
std::vector<Point> pts = circle_line_intersection(c, l); // (-1,0),(1,0)
std::vector<Point> tp = tangent_points(Point(2, 0), c);  // 两个切点
std::vector<Point> p = {Point(0,0), Point(1,0), Point(0,1), Point(1,1)};
Circle mc = min_circle_cover(p);                        // 圆心(0.5,0.5), r≈0.707
```

### 复杂度

交点/切点/外接圆 O(1)；`min_circle_cover` 期望 O(n)。

### 注意事项

- 圆与直线相切返回 1 个交点，相交返回 2 个（沿直线方向顺序），相离返回空。
- 两圆外离/内含返回空，内切/外切返回 1 个，相交返回 2 个，重合（无穷交点）返回空。
- `tangent_points`：点在圆内返回空，圆上返回该点，圆外返回 2 个切点。
- `circumcircle` 三点共线时退化为"最远两点为直径"的圆。
- `min_circle_cover` 用固定种子的 `mt19937` shuffle，结果确定、期望 O(n)。
