# 编码约定（Contributing / Style Guide）

本库是面向 OI/ACM 与工程实践的 **C++ 算法与数据结构模板库**（板子库）。
本文档约定所有头文件的编写规范。新增板子前请先阅读。

## 1. 语言与编译器

- 标准：**C++17**。
- 目标编译器：MSVC 2017 (14.16)+、GCC 7+、Clang 6+，代码必须能在三者下编译通过。
- 所有源文件使用 **UTF-8（无 BOM）** 编码（含中文注释）。
  MSVC 编译时必须加 `/utf-8` 选项（CMake 已在 `algo_lib` 目标上自动附加），
  否则在中文代码页(936)下会出现 C4819 警告与解析错误。
  命令行手编示例：`cl /std:c++17 /utf-8 /EHsc /I include ...`。
- **禁止**：`#include <bits/stdc++.h>`、`__int128`、GNU 扩展、VLA、C++20 特性。
- 尽量**避免**：`if constexpr`、结构化绑定、内联变量、`std::gcd`/`std::clamp`/`std::filesystem`
  等新库设施，以兼容 MSVC 2017；需要用位运算内置函数时使用条件编译或纯手写。
- 只使用 C++ 标准库，禁止第三方依赖。
- 头文件**禁止包含 `main` 函数**。

## 2. 头文件规范

- 每个板子一个头文件，路径 `include/<分类>/<snake_case>.hpp`。
- 文件**第一行**必须是 `#pragma once`。
- 所有声明必须放在 `namespace algo { ... }` 内。
- 每个头文件必须**自包含**：自己 include 用到的所有标准库头与库内头文件
  （库内头统一用 `#include "algo/xxx.hpp"` 风格，基于 `-I include`）。
- 禁止在不同头文件中重复定义同名函数 / 类 / 常量 / 类型；
  需要共享的实体（如 `ll`、`INF`、`Edge`）一律使用 `include/algo/common.hpp`。
- 每个文件顶部必须写**中文注释块**，格式如下：

```cpp
#pragma once
// ============================================================================
// algo/<分类>/<名字>.hpp —— 一句话功能
// ----------------------------------------------------------------------------
// 功能：详细说明（解决什么问题、支持哪些操作）
// 时间复杂度：xxx
// 空间复杂度：xxx
// 使用示例：
//   （简短可运行的代码片段，放在注释里）
// 注意事项：（边界条件、溢出、负数、模数要求等）
// ============================================================================
```

- 代码内注释用中文；标识符用英文；
  泛型使用 `template<typename T>`；整数类型默认 `long long`（别名 `ll`）。
- 数值板子必须注意**溢出**（乘法用 `__int128` 不允许时改快速乘 / 取模）。

## 3. 命名规范

| 类别       | 风格                | 示例                    |
| ---------- | ------------------- | ----------------------- |
| 类 / 结构体 | PascalCase         | `class FHQTreap`        |
| 函数       | snake_case          | `long long qpow(...)`   |
| 变量 / 参数 | snake_case          | `int cur_size`          |
| 类型别名   | 小写缩写            | `ll`、`ull`             |
| 常量       | 大写或全大写        | `INF`、`EPS`            |
| 宏         | 大写 + 前缀 `ALGO_` | `ALGO_DBG(...)`         |

## 4. 公共依赖

`include/algo/common.hpp` 提供：

```cpp
namespace algo {
using ll = long long;              // 整数默认类型
using ull = unsigned long long;
constexpr ll INF = 0x3f3f3f3f3f3f3f3fLL;  // 图论"不可达"初值，勿做加法
constexpr double EPS = 1e-9;       // 计算几何浮点精度
struct Edge { int to; ll w; };     // 通用带权边
}
```

需要时 `#include "algo/common.hpp"`，**不得重复定义**这些实体。

## 5. 如何新增一个板子

1. 按第 2 节格式创建 `include/<分类>/<名字>.hpp`。
2. 在 `docs/<分类>.md` 中补充该板子的功能、接口、示例与复杂度。
3. 在 `tests/smoke.cpp` 中 `#include` 该头文件（保证全库可编译），
   并尽量补一个正确性断言。
4. 在 `README.md` 的板子清单表格中登记一行。
5. 本地验证：

```bash
# GCC / Clang
g++ -std=c++17 -Wall -Wextra -O2 -I include tests/smoke.cpp -o build/smoke && ./build/smoke

# MSVC（需先进入 VS 开发环境）
cl /std:c++17 /W4 /EHsc /I include tests/smoke.cpp /Fe:build\smoke.exe
```

## 6. 质量要求

- 代码必须是**标准教科书实现**，保证正确性，可直接用于比赛或生产。
- 注意边界条件：空输入、单元素、`n = 0/1`、负权、重边、自环、大数溢出。
- 每个板子在文档中写明**时间复杂度 / 空间复杂度 / 适用条件**。
- 宁可多写注释，不要惜字如金；板子就是要让人"抄得明白"。
