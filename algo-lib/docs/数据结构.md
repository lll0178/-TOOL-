# 数据结构（ds）

本目录收录各类常用数据结构模板，全部位于 `namespace algo`，头文件置于 `include/ds/`。
除特别说明外，所有编号均从 1 开始（1-based）；基于 `vector` 的接口（ST 表、单调栈/队列、
笛卡尔树、KD 树、可持久化数组的建树输入等）使用 0-based 下标，各节均有注明。

> 公共依赖：`ll`、`INF`、`EPS`、`Edge` 定义于 `include/algo/common.hpp`，
> 使用方式 `#include "algo/common.hpp"`（基于 `-I include`）。

## 1. union_find.hpp —— 并查集三件套

**功能**：维护不相交集合。包含三种变体：

| 类 | 说明 |
| --- | --- |
| `DSU` | 普通并查集：路径压缩 + 按秩合并 |
| `WeightedDSU` | 带权并查集：维护元素到根的权值差（偏移量） |
| `RollbackDSU` | 可撤销并查集：按秩合并不做路径压缩，历史栈回退 |

**主要接口**

```cpp
class DSU {
    explicit DSU(int n);           // 编号 1..n
    int find(int x);               // 查根（路径压缩）
    bool unite(int a, int b);      // 合并；已同集合返回 false
    bool same(int a, int b);       // 是否同集合
    int size(int x);               // x 所在集合大小
};

class WeightedDSU {
    explicit WeightedDSU(int n);
    int find(int x);               // 查根（压缩时累加权值）
    ll weight(int x);              // val[x] - val[根]
    bool unite(int a, int b, ll w);// 声明 val[a]-val[b]=w；矛盾返回 false
};

class RollbackDSU {
    explicit RollbackDSU(int n);
    int find(int x);               // 查根（不压缩）
    bool unite(int a, int b);
    int snapshot();                // 返回历史栈长度
    void rollback(int s);          // 回退到快照 s
};
```

**用法示例**

```cpp
DSU dsu(5);
dsu.unite(1, 2); dsu.unite(2, 3);
bool ok = dsu.same(1, 3);     // true
int  sz = dsu.size(1);        // 3

// 食物链式偏移（mod 3：0 同类 / 1 吃根 / 2 被根吃）
WeightedDSU w(100);
w.unite(x, y, 1);             // 声明 x 吃 y
w.unite(x, y, 0);             // 声明 x 与 y 同类
int d = (int)((w.weight(x) - w.weight(y)) % 3 + 3) % 3;

RollbackDSU r(5);
r.unite(1, 2);
int snap = r.snapshot();
r.unite(3, 4);
r.rollback(snap);             // 撤销 (3,4) 合并
```

**复杂度**：DSU / WeightedDSU 单次操作近似 O(α(n))；RollbackDSU 的 find 为 O(log n)，回退 O(1)。

**注意事项**：编号 1..n；WeightedDSU 的权值做"累加"，适合取模场景，注意避免 `ll` 溢出。

## 2. fenwick.hpp —— 树状数组（BIT）

**功能**：一维/二维树状数组，支持四种形态。

**主要接口**

```cpp
template <typename T> class BIT {
    explicit BIT(int n);                 // 下标 1..n，初始全 0
    void add(int i, T v);                // 单点加
    T sum(int i) const;                  // 前缀和 a[1..i]
    T range_sum(int l, int r) const;     // 区间和
};

template <typename T> class BITRangeAdd {
    explicit BITRangeAdd(int n);
    void range_add(int l, int r, T v);   // 区间加（差分）
    T point_query(int i) const;          // 单点查
};

template <typename T> class BITRange {
    explicit BITRange(int n);
    void range_add(int l, int r, T v);   // 区间加
    T prefix_sum(int i) const;           // 前缀和
    T range_sum(int l, int r) const;     // 区间和（双 BIT）
};

class BIT2D {
    BIT2D(int n, int m);
    void add(int x, int y, ll v);                    // 单点加
    ll sum(int x, int y) const;                      // 前缀和
    ll range_sum(int x1,int y1,int x2,int y2) const; // 矩形和
};
```

**用法示例**

```cpp
BIT<ll> bit(100);
bit.add(3, 5);
ll s = bit.range_sum(1, 3);        // 5

BITRangeAdd<ll> bra(100);
bra.range_add(2, 7, 3);
ll v = bra.point_query(5);         // 3

BITRange<ll> br(100);
br.range_add(1, 100, 2);
ll t = br.range_sum(1, 100);       // 200

BIT2D b2(10, 10);
b2.add(1, 1, 3);
ll r = b2.range_sum(1, 1, 10, 10); // 3
```

**复杂度**：一维 O(log n)；二维 O(log n · log m)。空间：一维 O(n)，二维 O(n·m)。

**注意事项**：BITRange 依赖差分回推，`T` 需支持减法；BIT2D 固定 `long long`，注意溢出。

## 3. segment_tree.hpp —— 线段树（懒标记 / 最大子段和 / 矩形面积并）

**功能**：

1. `SegTreeSum`：区间加 + 区间赋值 + 区间求和/最值（双懒标记）。
2. `SegTreeMaxSubarray`：单点赋值 + 区间最大子段和。
3. `rectangle_area_union`：扫描线求矩形面积并。

**主要接口**

```cpp
class SegTreeSum {
    explicit SegTreeSum(int n);
    explicit SegTreeSum(const std::vector<ll>& a);
    void range_add(int l, int r, ll v);   // 区间加
    void range_set(int l, int r, ll v);   // 区间赋值
    ll query_sum(int l, int r);
    ll query_max(int l, int r);
    ll query_min(int l, int r);
};

class SegTreeMaxSubarray {
    struct Node { ll sum, lmax, rmax, best; };  // 区间信息
    explicit SegTreeMaxSubarray(int n);
    explicit SegTreeMaxSubarray(const std::vector<ll>& a);
    void point_set(int pos, ll v);        // 单点赋值
    Node query(int l, int r);             // 返回聚合信息，best 为最大子段和
};

struct Rect { ll x1, y1, x2, y2; };      // x1<x2, y1<y2
ll rectangle_area_union(const std::vector<Rect>& rects);
```

**用法示例**

```cpp
SegTreeSum st(std::vector<ll>{1,2,3,4,5});
st.range_add(1, 3, 10);
st.range_set(2, 4, 100);
ll s = st.query_sum(1, 5);

SegTreeMaxSubarray msa(std::vector<ll>{-2,1,-3,4,-1,2,1,-5,4});
ll best = msa.query(1, 9).best;          // 6

std::vector<Rect> rs = {{0,0,2,2},{1,1,3,3}};
ll area = rectangle_area_union(rs);      // 7
```

**复杂度**：线段树单次 O(log n)；面积并 O(k log k)（k 为矩形数）。空间 O(n) / O(k)。

**注意事项**：
- `SegTreeSum` 双懒标记下推顺序：先 set 后 add；赋值会清零该区间 add。
- `SegTreeMaxSubarray` 的 `merge` 规则：
  `sum=A.sum+B.sum; lmax=max(A.lmax, A.sum+B.lmax); rmax=max(B.rmax, B.sum+A.rmax); best=max(A.best, B.best, A.rmax+B.lmax)`。
- 矩形面积并要求 `x1<x2`、`y1<y2`，返回 `ll`。

## 4. persistent_segment_tree.hpp —— 主席树与可持久化数组

**功能**：
1. `PersistentSegTree`：静态区间第 k 小（离散化 + 动态开点，`root[i]` 为前缀 `[1..i]` 版本）。
2. `PersistentArray`：可持久化数组（历史版本单点改/查）。

**主要接口**

```cpp
class PersistentSegTree {
    PersistentSegTree();
    void build(const std::vector<ll>& a);  // 建树（离散化到值域）
    ll kth(int l, int r, int k);           // a[l..r] 第 k 小（1-based，返回原值）
};

class PersistentArray {
    explicit PersistentArray(int n);            // 下标 1..n
    int build(const std::vector<ll>& a);       // 返回初始版本根
    int update(int prev_root, int pos, ll val);// 单点改，返回新根
    ll query(int root, int pos) const;         // 单点查
};
```

**用法示例**

```cpp
PersistentSegTree pst;
pst.build(std::vector<ll>{3,1,4,1,5});
ll v = pst.kth(1, 5, 2);          // 1（整体第 2 小）

PersistentArray pa(5);
int r0 = pa.build(std::vector<ll>{1,2,3,4,5});
int r1 = pa.update(r0, 3, 99);
ll a3 = pa.query(r1, 3);          // 99
ll a3_old = pa.query(r0, 3);      // 3
```

**复杂度**：建树 O(n log n)，每次查询/修改 O(log n)。空间 O(n log n)。

**注意事项**：`kth` 的 `l,r` 为 1-based，要求 `1 <= k <= r-l+1`；0 号节点为空节点占位。

## 5. sparse_table.hpp —— ST 表

**功能**：离线 RMQ 类查询。要求 `Merge` 幂等（`merge(x,x)==x`），如 max / min / gcd。

**主要接口**

```cpp
template <typename T, typename Merge = std::function<T(T,T)>>
class SparseTable {
    SparseTable(const std::vector<T>& a, Merge merge);
    T query(int l, int r);   // 0-based 闭区间
};
```

**用法示例**

```cpp
std::vector<ll> a = {1,3,2,9,7};
SparseTable<ll> st(a, [](ll x, ll y){ return std::max(x, y); });
ll mx = st.query(1, 3);            // a[1..3] 最大值 = 9

SparseTable<ll> stg(a, [](ll x, ll y){
    while (y) { ll t = x % y; x = y; y = t; }
    return x;                       // gcd（手写，勿用 std::gcd）
});
```

**复杂度**：预处理 O(n log n)，查询 O(1)。空间 O(n log n)。

**注意事项**：下标 0-based；`Merge` 必须幂等（查询用两段覆盖，可能有交叠）；不支持修改。

## 6. treap.hpp —— FHQ Treap（无旋）

**功能**：
1. `FHQTreap`：按值分裂的有序集合（重复值计数）。
2. `TreapSeq`：按大小分裂的序列（区间翻转/加/求和/插入/删除）。

**主要接口**

```cpp
class FHQTreap {
    FHQTreap();
    void insert(ll x);
    void erase(ll x);
    int rank(ll x);        // 小于 x 的数量 +1（1-based）
    ll kth(int k);         // 第 k 小（1-based）
    ll prev(ll x);         // 前驱，无则 -INF
    ll next(ll x);         // 后继，无则 INF
    int size();
};

class TreapSeq {
    TreapSeq();
    void build(const std::vector<ll>& a);
    void insert(int pos, ll v);      // 位置 pos 插入（1-based）
    void erase(int pos);
    void reverse(int l, int r);
    void add(int l, int r, ll v);
    ll query_sum(int l, int r);
    std::vector<ll> inorder();
};
```

**用法示例**

```cpp
FHQTreap t;
t.insert(5); t.insert(3); t.insert(5);
int r = t.rank(5);           // 2
ll k = t.kth(2);             // 5

TreapSeq seq;
seq.build(std::vector<ll>{1,2,3,4,5});
seq.reverse(2, 4);           // {1,4,3,2,5}
seq.add(1, 3, 10);
ll s = seq.query_sum(1, 5);  // 45
```

**复杂度**：所有操作期望 O(log n)。空间 O(n)。

**注意事项**：`TreapSeq` 位置参数 1-based；懒标记 rev/add 下推顺序见源码注释（对 sum 可交换）。

## 7. splay.hpp —— Splay（文艺平衡树）

**功能**：序列 Splay，支持指定位置插入/删除、区间翻转、区间加、区间求和、中序导出。

**主要接口**

```cpp
class SplaySeq {
    SplaySeq();
    void build(const std::vector<ll>& a);
    void insert(int pos, ll v);
    void erase(int pos);
    void reverse(int l, int r);
    void add(int l, int r, ll v);
    ll query_sum(int l, int r);
    std::vector<ll> inorder();
};
```

**用法示例**

```cpp
SplaySeq seq;
seq.build(std::vector<ll>{1,2,3,4,5});
seq.reverse(2, 4);
seq.add(1, 3, 10);
ll s = seq.query_sum(1, 5);   // 45
seq.insert(1, 100);
```

**复杂度**：所有操作均摊 O(log n)。空间 O(n)。

**注意事项**：0 号节点为哨兵，另有 -INF/+INF 两个边界节点；位置参数 1-based；
区间提取用 `splay(第 l 个)` 到根 + `splay(第 r+2 个)` 到根右儿子。

## 8. hld.hpp —— 树链剖分

**功能**：树上路径/子树操作转 dfs 序区间，内部集成区间加+区间和线段树。

**主要接口**

```cpp
class HLD {
    explicit HLD(int n);
    void add_edge(int u, int v);      // build 前调用
    void build(int root = 1);         // add_edge 全部完成后调用
    void set_val(int u, ll v);        // 单点赋值（扩展接口）
    void path_add(int u, int v, ll w);
    ll path_sum(int u, int v);
    void subtree_add(int u, ll w);
    ll subtree_sum(int u);
};
```

**用法示例**

```cpp
HLD hld(5);
hld.add_edge(1,2); hld.add_edge(1,3);
hld.add_edge(3,4); hld.add_edge(3,5);
hld.build(1);
hld.path_add(4, 5, 10);
ll s = hld.subtree_sum(3);
```

**复杂度**：build O(n)；路径操作 O(log² n)；子树操作 O(log n)。空间 O(n)。

**注意事项**：节点 1..n；初始点权全 0（可用 `set_val` 设置）；两遍 dfs 为递归实现，极深链注意栈空间。

## 9. cartesian_tree.hpp —— 笛卡尔树

**功能**：O(n) 单调栈建小根笛卡尔树（中序 = 原数组，父值 ≤ 子值；相等时下标小者为祖先）。

**主要接口**

```cpp
template <typename T> struct CartesianNode { int l, r, fa; };

template <typename T>
std::vector<CartesianNode<T>> build_cartesian_tree(const std::vector<T>& a);
```

**用法示例**

```cpp
std::vector<int> a = {5, 3, 7, 1, 6};
auto t = build_cartesian_tree(a);
// t[i].l/.r/.fa 为节点 i 的左/右儿子/父亲（0-based，无则 -1）；根 fa == -1
// 区间最值：a[l..r] 最小值 = LCA(l, r)（笛卡尔树上）对应值
```

**复杂度**：O(n) 时间，O(n) 空间。

**注意事项**：返回 `vector` 大小 == `a.size()`，节点编号与原下标一致（0..n-1）。

## 10. kdtree.hpp —— 二维 KD-Tree

**功能**：二维点集最近点（距离平方）与矩形内点数统计。

**主要接口**

```cpp
struct Point2D { ll x, y; };

class KDTree {
    explicit KDTree(const std::vector<Point2D>& pts);
    ll nearest_dist2(const Point2D& p);                    // 最近距离平方
    int count_in_rect(ll x1, ll y1, ll x2, ll y2);         // 矩形内点数（含边界）
};
```

**用法示例**

```cpp
std::vector<Point2D> pts = {{0,0},{1,1},{3,2},{5,3}};
KDTree kd(pts);
ll d = kd.nearest_dist2(Point2D{3,1});   // 1
int c = kd.count_in_rect(0,0,3,2);       // 3
```

**复杂度**：建树 O(n log n)（`nth_element` 中位数划分）；查询期望 O(√n)，最坏 O(n)。

**注意事项**：距离平方用 `ll`，坐标过大（如 >3e9）可能溢出；空集 `nearest_dist2` 返回 `INF`、`count_in_rect` 返回 0。

## 11. lct.hpp —— Link-Cut Tree

**功能**：动态树（森林），支持加边、删边、换根、查根、单点赋值、路径点权和。

**主要接口**

```cpp
class LinkCutTree {
    explicit LinkCutTree(int n);
    void makeroot(int x);          // 换根
    int findroot(int x);           // 查所在树根
    void link(int x, int y);       // 连边（内部先 makeroot，避免成环）
    void cut(int x, int y);        // 删边（仅当直接相连）
    void set_val(int x, ll v);     // 单点赋值
    ll query_path(int x, int y);   // 路径点权和
};
```

**用法示例**

```cpp
LinkCutTree lct(5);
lct.set_val(1, 10);
lct.link(1, 2); lct.link(2, 3);
ll s = lct.query_path(1, 3);   // 10
lct.cut(1, 2);
```

**复杂度**：所有操作均摊 O(log n)。空间 O(n)。

**注意事项**：节点 1..n，0 号为哨兵；`cut` 仅当 x、y 直接相连才生效。

## 12. block.hpp —— 分块

**功能**：整块懒标记 + 散块暴力；每块维护排序副本。

**主要接口**

```cpp
class SqrtDecomp {
    explicit SqrtDecomp(const std::vector<ll>& a);
    void range_add(int l, int r, ll v);   // 区间加
    ll range_sum(int l, int r);           // 区间和
    int count_less(int l, int r, ll x);   // 区间内 < x 的元素个数
};
```

**用法示例**

```cpp
SqrtDecomp sd(std::vector<ll>{5,1,4,1,3,9});
sd.range_add(1, 4, 2);
ll s = sd.range_sum(2, 5);        // 15
int c = sd.count_less(1, 6, 5);   // 3
```

**复杂度**：`range_add` / `range_sum` O(√n)；`count_less` O(√n log n)。空间 O(n)。

**注意事项**：下标 1-based；块大小 `max(1,(int)sqrt(n))`；散块修改后重建排序副本。

## 13. monotonic.hpp —— 单调栈 / 单调队列

**功能**：求每个位置左/右侧第一个更大/更小元素，滑动窗口最值。

**主要接口**

```cpp
template <typename T> std::vector<int> next_greater(const std::vector<T>& a);  // 右侧第一个更大（下标，无则 -1）
template <typename T> std::vector<int> next_smaller(const std::vector<T>& a);  // 右侧第一个更小
template <typename T> std::vector<int> prev_greater(const std::vector<T>& a);  // 左侧第一个更大
template <typename T> std::vector<int> prev_smaller(const std::vector<T>& a);  // 左侧第一个更小

template <typename T> std::vector<T> sliding_window_min(const std::vector<T>& a, int k);
template <typename T> std::vector<T> sliding_window_max(const std::vector<T>& a, int k);
```

**用法示例**

```cpp
std::vector<int> a = {1,3,2,4};
auto ng = next_greater(a);           // {1,3,3,-1}
auto mn = sliding_window_min(a, 2);  // {1,2,2}
auto mx = sliding_window_max(a, 3);  // {3,4}
```

**复杂度**：均为 O(n)。空间 O(n)。

**注意事项**：下标 0-based，"无"返回 -1；严格比较；滑动窗口 `k > n` 或 `k <= 0` 返回空 `vector`。
